相对于老代码,基于F28377S的代码进行了非常大的重构

1.由于F28377S自带FPU,所以直接摒弃了老代码的IQMath计算浮点数的方式,因为IQMath涉及到复杂的移位操作,抽象的数值表示,容易导致写错写漏.

2.数据管理方式改变:
现在不会有孤立的变量存在,所有有价值的变量都采用数据域的方法管理;
收紧了数据的作用范围,严格区分了全局变量和局部变量,想要读取static数据,只能使用probe数据域进行读取,使用scalpel数据域进行修改.

3.整个代码分三个层次,顶层调度层,中层任务层,底层配置层:
其中顶层负责初始化,任务调度等工作,一些常用的函数也会直接放在系统上供下面两层使用;
中层就是干活的层,负责逆变器一切的,包括状态机,电流环,直流环,通讯等功能;
底层负责MCU基本功能配置,如ADC配置,逆变器配置,与老代码相区别的是,所有寄存器操作都被严格限制在了bsp.c里面.


4.调度使用前后台系统,绝大多数任务都由定时器触发,少部分任务条件触发,如ac_ctrl由ADC触发,dc_ctrl由过零点触发...

5.当前逆变器不涉及到任何国家的安规,且没有下垂控制,高低穿,防孤岛等功能
